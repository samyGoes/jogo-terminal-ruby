## Como jogar?
> Para jogar este jogo você precisa ter o [ruby](https://www.ruby-lang.org/pt/documentation/installation/) instalado.

Depois de instalar abra o terminal e cole este comando para clonar o repositório:
~~~cmd
git clone https://github.com/samyGoes/jogo-terminal-ruby.git
~~~
> Você precisa ter o [GIT](https://git-scm.com/downloads) instalado para executar o comando acima.

Acesse a pasta do jogo:
~~~cmd
cd jogo-terminal-ruby
~~~

Depois cole este para instalar as dependências do jogo:
~~~cmd
bundle install
~~~

Acesse a pasta bin:
~~~cmd
cd bin
~~~

E execute o jogo :)
~~~cmd
ruby main.rb
~~~
